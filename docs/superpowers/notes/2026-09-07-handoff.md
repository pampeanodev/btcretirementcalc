## Things that will otherwise be rediscovered the hard way

**`test/setup.ts`'s canvas stub is load-bearing.** It returns the canvas element
for `context.canvas`, and that one property is why chart.js works under jsdom at
all. chart.js only accepts a context whose `.canvas` is identical to the element
it asked about; without it `acquireContext` returns null, the `Chart` constructor
returns early leaving `this.canvas` null, and the next `chart.update()` throws
from inside chart.js and takes the whole tree into the router's error boundary.
Every re-render triggers that update, because the options object is rebuilt each
render. It looked exactly like toggling the theme crashed the app. It did not.

**The English-only test suite cannot see a hardcoded string.** In English,
`t("strategy.optimized-title")` and the literal it returns are the same string,
so every assertion passes either way. That is how four tasks shipped hardcoded
titles with a green suite. `test/StrategyComparison.spec.tsx` now renders in
Spanish specifically to close that hole, and `test/locales.spec.ts` compares key
sets across bundles. Add to both when adding copy.

**`rtk` summarises command output.** It rewrites shell commands through a
token-saving proxy, which is usually invisible and occasionally swallows the line
you needed — including a `prettier --check` failure that was reported as clean for
most of a session. Use `rtk proxy "<cmd>"` for raw output whenever a result looks
too tidy.

**Git and GitHub.** The remote uses the SSH host alias
`git@github.com-pampeanodev:` — a plain `github.com` remote pushes as the wrong
account. `gh auth switch` alone is not enough. `main` is guarded by a repository
**ruleset** (not classic branch protection, so the protection API 404s): it
requires a PR and a passing CodeQL scan. Auto-merge is disabled on the repo, so a
PR has to be merged by hand once CodeQL finishes — a few minutes after push.

**Never `git checkout <file>` to undo an experiment.** Uncommitted work in that
file goes with it. Copy the file to the scratchpad first and restore from the
copy. This cost a rewrite in this session.

## What the audit settled, so it is not re-litigated

The optimized strategy's arithmetic was checked against three hypotheses —
mis-discounting, under-selling, and mis-projecting the retirement age — and all
three were refuted numerically. Total sold matches a closed form rebuilt from the
inputs to ten decimal places; retiring a year earlier fails in every scenario
tested. Both properties are now pinned by tests that die under mutation.

The large bitcoin residual at death is not slack. The lifetime requirement falls
8.5–21.5% a year depending on the growth rate, and the decision is taken once a
year, so it overshoots by roughly one year's drop — measured at 0.22× to 0.88× of
it. It looks enormous in dollars only because it then compounds for five decades.

What is left to distrust is the model, not the code: a constant CAGR held for 56
years with no volatility. That is item 3 above.
